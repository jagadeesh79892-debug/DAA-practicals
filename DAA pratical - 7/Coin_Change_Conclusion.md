# Conclusion

This program successfully calculates the number of ways to make a given amount using the available coin denominations. It uses a **Dynamic Programming** approach to avoid repeated calculations and efficiently solve the Coin Change Combination problem.

The program considers each coin and amount systematically and stores the results in a DP table. This makes the solution efficient, with a time complexity of **O(m × n)** and a space complexity of **O(m × n)**.

Overall, the program demonstrates the practical use of **Dynamic Programming** for solving a common combinatorial problem and provides the total number of possible coin combinations for the given amount.
